# Contributing

Thank you for considering a contribution.

1. Open an issue describing the change or defect.
2. Fork the repository and create a focused branch.
3. Keep secrets and generated local state out of commits.
4. Run `powershell -ExecutionPolicy Bypass -File .\verify.ps1` from the repository root.
5. Submit a pull request describing the behavior, tests and security impact.

Keep changes small, preserve role-based access boundaries and add tests for new backend behavior. Security vulnerabilities must be reported privately as described in `SECURITY.md`.
