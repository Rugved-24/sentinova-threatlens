# Security policy

## Supported version

The latest commit on the default branch is the supported portfolio version.

## Reporting a vulnerability

Do not open a public issue for a suspected vulnerability. Contact the repository owner privately through the security contact listed on their GitHub profile and include:

- the affected component and version;
- reproducible steps or a minimal proof of concept;
- the likely impact; and
- any suggested mitigation.

Please allow reasonable time to investigate before public disclosure. Never include real credentials, private keys, access tokens, personal data or live exploit data in a report.

## Deployment warning

The included accounts and deterministic data are for demonstration. Rotate all secrets, disable demo mode, restrict network access, configure trusted TLS and use provider-managed secret storage before a real deployment.
